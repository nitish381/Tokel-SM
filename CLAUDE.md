# Tokel — instructions for Claude

Before creating any Tokel design, social media graphic, cover, post, deck, ad or web page, read **[TOKEL_BRAND_GUIDELINES.md](TOKEL_BRAND_GUIDELINES.md)** and follow it.

- Website: https://tokel.org/
- Figma source: https://www.figma.com/design/IcLJaFxcYcFIMWzKDBgR32/Tokel-LP-Redesign
- When asked for a social cover or post (e.g. "create SM cover for Twitter/LinkedIn"), use the exact size, ratio and safe zone in section 3 of the guidelines.
- Visual style: social covers use the landing-page hero skyline photo with navy overlay (see the Social Media page in Figma). Other graphics use 3D abstract architecture (glass/blue buildings, cubes, blocks). Don't use generic stock photography.
- Font: Space Grotesk. Colors: #000088, #001D6B, #010115, #A6C2D3, #F2FAFF.
